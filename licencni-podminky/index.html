9. Služby třetích stran

9.1 Software lze používat bez připojení k internetu. Připojení využívají jen tyto funkce:

  1. vyhledání subjektů v registru ARES,
  2. kontrola úhrad přes API banky (Fio banka),
  3. odesílání hlášení o chybách, pouze se souhlasem uživatele.

9.2 Užívání služeb třetích stran se řídí jejich podmínkami. Autor neodpovídá za jejich dostupnost, správnost poskytnutých údajů ani jejich změny. Nedostupnost služeb třetích stran není vadou Software.

Doporučuje se používat token pouze ke sledování účtu, bez oprávnění zadávat platby.
